# AndroLink - versions publiques

Ce depot heberge exclusivement les versions publiques officielles d'AndroLink pour Windows.

Chaque release stable fournit :

- l'installateur universel Windows ;
- une version portable pour Windows 10 ;
- une version portable pour Windows 11.

AndroLink consulte uniquement l'API des releases de ce depot. Avant toute installation, l'application verifie l'empreinte SHA-256 publiee par GitHub.

Le code source et le suivi du developpement ne sont pas publies dans ce depot de distribution.
