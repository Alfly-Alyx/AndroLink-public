## 🇫🇷 Français

### Télécharger

➡️ **[Voir la dernière version stable](https://github.com/Alfly-Alyx/AndroLink-public/releases/latest)**

Chaque version Windows contient :

- un installateur unique qui choisit l'interface adaptée à Windows 10 ou Windows 11 ;
- une archive portable pour Windows 10 ;
- une archive portable pour Windows 11.

AndroLink est fourni pour **Windows x64** et accompagne les téléphones sous **Android 5.0 ou plus récent**. Les versions macOS et Linux sont encore en cours de validation et ne sont pas proposées ici pour le moment. Support de iOS à venir.

### Ce que fait AndroLink

- parcourir et transférer des fichiers, photos et vidéos ;
- gerer contacts, SMS, notifications et applications ;
- afficher et contrôler le téléphone avec **AndroLink Remote** ;
- créer des sauvegardes locales et retrouver plus facilement les données du téléphone.
- configurer le controle parental
- sauvegarde complète en local et chiffré de votre téléphone et restauration sur n'importe quel autre téléphone, android ou non.

### Vie privée et mises à jour

AndroLink privilégie les échanges locaux entre le téléphone et l'ordinateur. Le vérificateur intégré consulte uniquement les releases de ce dépôt public. Il choisit le bon fichier Windows et contrôle son empreinte **SHA-256 publiée par GitHub** avant de proposer son installation.

Les exécutables sont actuellement produits sans certificat commercial de signature de code. Windows SmartScreen peut donc afficher un avertissement : vérifiez toujours que le fichier provient bien de cette page de releases.

Ce dépôt sert uniquement à distribuer les versions publiques. Il ne contient pas le code source. Les licences et mentions des composants tiers sont incluses dans chaque paquet.

## 🇬🇧 English

### Download

➡️ **[Open the latest stable release](https://github.com/Alfly-Alyx/AndroLink-public/releases/latest)**

Every Windows release contains:

- one installer that selects the right interface for Windows 10 or Windows 11;
- one portable archive for Windows 10;
- one portable archive for Windows 11.

AndroLink is distributed for **64-bit Windows** and works with phones running **Android 5.0 or later**. macOS and Linux editions are still being validated and are not distributed here yet. iOS support is planned for a future release.

### What AndroLink does

- browse and transfer files, photos, and videos;
- manage contacts, SMS messages, notifications, and apps;
- display and control the phone through **AndroLink Remote**;
- create local backups and make phone data easier to find;
- configure parental controls;
- create a complete, encrypted local backup of your phone and restore it to any other phone, whether it runs Android or not.

### Privacy and updates

AndroLink favors local communication between the phone and the computer. Its built-in updater only checks releases from this public repository. It selects the correct Windows package and verifies the **SHA-256 digest published by GitHub** before offering to install it.

The executables are currently built without a commercial code-signing certificate. Windows SmartScreen may therefore display a warning: always make sure the file comes from this releases page.

This repository is only used to distribute public builds. It does not contain the source code. Licenses and notices for third-party components are included in every package.
